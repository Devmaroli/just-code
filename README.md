# just-code

Small, standalone creative-tool scripts.

## After Effects — Replace Footage by Size

Panel where you pick a folder of new images or videos. The script matches those files to footage already in the project by **pixel size** (or file name) and replaces the project items in place.

| Path | Purpose |
|------|---------|
| `scripts/ReplaceFootageBySize.jsx` | After Effects ScriptUI panel |
| `scripts/README-ReplaceFootageBySize.md` | Install, matching rules, and usage |

**File → Scripts → Run Script File…** and choose the `.jsx`, or copy it into After Effects’ `Scripts/ScriptUI Panels` folder and open it from **Window**.
